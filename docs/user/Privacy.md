# EcoTrack Privacy Policy

EcoTrack AI is built on a privacy-first foundation.

## Data Collection
- We collect account details (email, optional display name) for authentication.
- Assessment response data is stored securely in your private user profile in Firebase Firestore.

## Data Sharing
- **No Data Selling:** We do not sell or monetize personal user data.
- **Public Aggregates:** Global statistics (e.g. "Total CO₂ tracked") are anonymized and aggregated across all users without exposing individual identity.

## User Control
- You can export your data at any time.
- You can enable Anonymous Mode for community leaderboards.
- You can request complete deletion of your account and associated records.
