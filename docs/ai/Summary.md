# EcoTrack AI High-Level Summary

## Product Overview
EcoTrack AI is a science-backed, privacy-first carbon footprint calculator and intelligence platform. It allows individual users to measure, analyze, track, and gamify their carbon reduction efforts using GHG Protocol standards and peer-reviewed emission datasets.

## Key Capabilities
1. **Interactive Real-Time Simulator:** Live emissions estimation without mandatory signup.
2. **Multi-Category Assessments:** Granular tracking across Transport, Energy, Food, Waste, and Shopping.
3. **Real-time Community Aggregation:** Anonymous global stats and leaderboards powered by Firebase Firestore and Cloud Functions.
4. **PDF Report Export:** Downloadable structured carbon summary reports.

## Core Tech Stack
- **Frontend Framework:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Custom Design System Tokens, CSS Glassmorphism
- **State & Routing:** React Router v7, React Context API
- **Backend & Database:** Firebase Auth, Firestore, Firebase Cloud Functions (Node 20)
- **Graphics & Data Viz:** Framer Motion, Chart.js, Lucide Icons
